FloodGuard

A flood-risk prediction system that uses an LSTM model to analyze weather data and displays predictions through a React and Node.js dashboard.

Model integration

Problem & Approach

The team aimed to estimate flood risk from weather data and make the predictions accessible through a web dashboard. The system combines weather inputs, an LSTM prediction model, and a React and Node.js application.

What I Learned

Through this project, I learned how LSTM-based deep learning can be applied to weather data and how to integrate a prediction model into a web-based application.
